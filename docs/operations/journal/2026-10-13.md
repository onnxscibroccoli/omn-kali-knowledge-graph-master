### Security decisions

1. Neither Google login nor Chrome saved passwords provides authorization to arbitrary websites; per-relying-party OAuth consent/MFA remains necessary. **Do not sync the owner's full Chrome/Google Password Manager profile to an ephemeral GitHub runner.**
2. The Android app's Google/GitHub sign-in authenticates the **companion gateway only**; separate vendor login and approved scopes are needed. Prevent public exposure of VNC endpoints; noVNC is not authentication. Use HTTPS + OIDC + device authorization + per-session short-lived tokens; never log private callback URLs.
3. GitHub-hosted Actions are appropriate for **repository software build/test** including ephemeral MCP/browser integration tests; its August 27, 2026 terms limit unrelated general computing, public serverless and interactive hosted uses. Long-lived auth/website automation control remains on owner-approved OCI or equivalent servers, not hosted Actions.
4. ChatGPT data should be obtained via the **official account export** or Privacy Portal, then imported locally into Termux/private Android storage and a searchable SQLite FTS5 index. No history exports, tokens, or browser cookies in GitHub or public cloud artifacts. Plaintext on Android remains sensitive and is less secure than encrypted-at-rest local storage.
5. Broad autonomous development is bounded by deterministic policy: scoped task permissions, cost governor, nonsecret event journal, idempotency/retry, per-site post-login verification, explicit human approval for billing and destructive steps.
